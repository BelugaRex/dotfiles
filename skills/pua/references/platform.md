# PUA Platform — Copilot 本地指令系统

本文件适配固定上游 v3.5.1 的本地指令设计。仅本地运行，不提供账号、远端配置/模板、支付、在线排行榜、统计或 session 上传；不得收集电话、邮箱、token 或支付资料。

## 当前状态与授权

- 没有注册的 hooks、自动计数、后台进程或状态恢复。
- 普通模式仅作用于当前对话；不自动读写 `~/.pua/`。持久化须获得用户对具体文件的明确授权。
- 运行计数、验收、检查点、风味锁定见 `runtime-contract.md`。

## 一、本地指令

以下是 `/pua` 或自然语言的意图，不表示宿主注册了多个命令：

| 意图 | 本地处理 |
|------|----------|
| KPI、复盘、周报 | 按 `pro-mode.md` 基于可见工作证据生成 |
| 段位 | 展示下方梗表，不查询账号或排名 |
| flavor、味道 | 本对话切换风味，失败不覆盖用户锁定 |
| 述职、代码美化、反 PUA | 使用已安装参考与用户提供内容；不校验套餐 |

不查缓存、不拉远端 prompt、不注册、不付费。KPI 只据当前会话统计，未知值标为未知。
